# BookPJ

Djangoを用いた書籍管理アプリです。

## 概要

書籍の登録・一覧表示・詳細表示などを行う基本的なWebアプリです。

Djangoの基本的なCRUD処理の学習を目的として作成しました。

## 使用技術

* Python
* Django
* PostgreSQL

## 主な機能

* 書籍一覧表示
* 書籍詳細表示
* 書籍登録・編集・削除（CRUD）

## 学習ポイント

* Djangoの基本構造（Model / View / Template）
* Class Based View（CBV）の理解
* PostgreSQLとの連携
* .envによる環境変数管理
